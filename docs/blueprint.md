# **App Name**: PrepAI

## Core Features:

- Content Ingestion: Streamlined interface for uploading and managing study materials (PDF, DOC, PPT).
- Quiz Builder: Customizable quiz generation based on USMLE blueprint categories and difficulty.
- AI Quiz Generation: AI powered quiz and flashcard generation from user uploaded documents
- Interactive Practice: Intuitive MCQ interface with immediate feedback, answer rationales, and flashcard display.
- Personalized Study Plan: Dashboard displaying readiness score, mastery levels, performance trends, and a personalized study plan with AI recommendations for topics that need review or focused quizzing; displays system-generated suggestions.
